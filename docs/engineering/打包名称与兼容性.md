# 打包名称与兼容性

当前公开名称为 **麦克风混音助手**。界面、系统权限提示、安装引导及分发产物使用这一名称。

## 名称来源与产物

`apps/mixer-gui/tauri.conf.json` 的 `productName` 是打包名称来源：

- macOS 打包脚本和 `m0/tools/app_verify.sh` 通过共用的 `tools/app-product-name.sh` 读取它。
- App、DMG 文件名、DMG 卷名、首次打开说明及挂载后的 App 校验路径使用同一个名称。
- Windows 打包脚本直接读取该配置，只接受当前产品名和版本对应的 NSIS 安装包；其他名称或版本的旧包不会被当成本次产物。
- 名称允许中文与空格。两端拒绝空名称和不能用作跨平台文件名的字符。

可以先查看 macOS 产物路径，命令不会构建、签名、挂载磁盘或操作音频设备：

```sh
./apps/mixer-gui/build-app.sh --print-artifact-paths
./apps/mixer-gui/build-app.sh --print-first-open-note
./m0/tools/app_verify.sh --print-app-path
```

公开名称调整后，应用 identifier 仍为 `dev.local.mixer`，可执行文件仍为 `mixer-gui`，用户配置目录沿用原路径。目录和文件选择不受产品名称影响。

## 回归与验证边界

```sh
node --test tools/test-app-packaging.js
```

这组回归实际运行交付的 macOS 脚本，覆盖当前名、中文带空格名、英文带空格名和无效名称，并真正渲染 DMG 内的首次打开说明，防止中文标点紧邻变量时被 Bash 当作变量名的一部分；同时检查两端名称使用及 macOS 四项系统用途说明。它不需要真实声卡，不关闭正在运行的 App，也不修改用户配置。

Windows 原生脚本回归通过以下命令运行，包含名称解析、中文空格名、旧名称/旧版本包筛选和原有冒烟门禁：

```powershell
.\apps\mixer-gui\build-app-windows.ps1 -TestSmokeHarness
```

两项均接入质量 CI；macOS 检查接入 `tools/check-all.sh`。Windows CI 执行 PowerShell 原生回归，不能用 macOS 上的源码检查代替其执行结果。真实 NSIS 安装和 macOS App/DMG 签名仍由对应平台的打包脚本校验。

历史调研中的产品类别名称及旧版本变更记录保留原文；当前使用指令与打包路径采用新名称。

## 软件简介与目录支持

顶栏「关于」展示软件简介、正式播放和本机试听的区别、连接方法及版本信息。
名称、版本通过共用的 `app_info` 命令读取打包配置；打开或关闭窗口不会改变音频会话。
对 Windows 的 VB-CABLE，说明明确区分软件输出 `CABLE Input` 与目标应用麦克风 `CABLE Output`。
当前面向用户的桌面、CLI 和手机遥控文案使用「对方」。

音频来源不限于 `~/Downloads`。原生选择器接受任意有读取权限的文件夹或音频文件；
目录扫描只扫描当前层。载入文件夹替换列表，「添加文件」可以从不同目录追加。
macOS 下载、桌面、文稿受系统隐私权限保护，首次访问需要允许读取；外部存储需要保持挂载且可读。

配置保存、恢复的 `~/` 展开与 GUI 使用同一主目录规则：macOS 使用 `HOME`，Windows 使用 `USERPROFILE`。
绝对路径和 UNC 路径保持不变，测试通过平台和环境注入验证，不修改全局环境变量。
