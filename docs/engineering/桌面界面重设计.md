# 桌面界面重设计

## 已确认的方向

用户于 2026-10-13 确认采用「侧边混音」和简洁音效卡片，主要用于游戏或互动中快速触发音效。
界面使用克制的中性色与暖橙色强调色，跟随系统明暗主题；macOS 和 Windows 共用交付 DOM、样式和 IPC。
右上角「更多功能」中的「界面主题」提供跟随系统、浅色与深色，立即切换并保存为本机偏好。
手动主题不受系统变化覆盖，切回跟随系统后立即采用当前系统外观；主题切换不影响音频操作。
保留系统原生标题栏、窗口隐藏及 Dock / 托盘恢复策略。

## 信息与操作

- 左上角名称与副标题各占一行，品牌区保留文本宽度；最小窗口不能将副标题末字挤到第二行。
- 主区域为音效库：添加文件、搜索、标签筛选、排序，以及播放、试听和「…」详情入口。
- 卡片不常驻单条音量滑杆；详情中提供实时音量、名称、标签、热键、排序和移除。
  音量按稳定 ID 寻址；名称、标签和库顺序在音效关闭后修改。
- 右侧混音区常驻麦克风音量、音效总音量、循环和监听状态。音量滑杆与数值输入同步。
  监听是会话启动配置，运行时明确显示状态与更改方法，不能用无效开关假装即时改变。
- 连接设置包含真实输入、虚拟输出、监听输出、缓冲、热键、目录及遥控。
  平台指导来自原生 `platform_info`；Windows 保留 CABLE Input → CABLE Output 说明。
- 底部播放器展示原生播放类型、音效名称、真实进度和停止入口；停止始终可见。
  电平代表送往虚拟设备的混合信号，不能宣称目标应用或对方一定已经收到。
- 自检、校准、排查、二维码和关于使用独立面板；面板阻止窗口播放快捷键，支持 Escape、焦点约束和恢复。
- 不为装饰生成虚假波形、时长或跳动电平；未知时长显示「启动后读取时长」。

## 状态与失败场景

| 场景 | 预期 |
|---|---|
| 正式播放 / 试听 / 停止 / 切换 | 沿用共用 Host 票据和单音效约束；只依据已接纳的原生状态显示当前音效 |
| 搜索隐藏正在播放的卡片 | 底部仍显示当前音效与进度，可直接停止 |
| 原生热键或手机切换 | 轮询同步卡片及底部播放器，不重开会话 |
| 详情中调音量 | 实时发送稳定 ID，保存最新值；不误触播放 |
| 关闭详情 / 连接 / 关于 | 不改变播放、音量或会话，仅恢复界面焦点 |
| 旧状态或命令迟到 | 不覆盖最新选择和底部播放器 |
| 未启动 / 待机 | 明确区分设备关闭与人声继续转发；试听仍可使用 |
| 最小窗口与长名称 | 音效库与侧栏各自滚动，停止固定；名称截断保留完整可访问名称与详情 |
| IPC 失败 / 虚拟设备缺失 | 保留可见提示及排查入口，不显示虚假成功 |

## 验证方式

交付 DOM → 模拟 IPC 回归覆盖原有播放组合、增益和配置，并新增详情、焦点、筛选、底部状态和双端引导。
使用浏览器对交付源码验证默认 920×660、最小 660×500、明暗主题、长名称及多条音效。
浏览器使用隔离的模拟 IPC，不操作音频硬件或用户配置；该证据不代表 Windows WebView2 或真实音频已验收。
音频播放规则继续由已有 Host / PCM 回归覆盖，新增结果记录在有日期的验证台账。

## 2026-10-13 实施与复核

上述布局已落到 `apps/mixer-gui/dist/` 交付源码，保留原有共用播放模型和 Host 请求顺序。
新增 21 项 GUI 控件回归，完整 GUI 90 项、JavaScript 116 项通过。覆盖详情增益、元信息与热键关联、
焦点恢复、面板快捷键、搜索后的播放状态、监听只读说明、双端连接文案和保存失败。

独立复核与浏览器验收发现的问题已修复：

- 播放或试听按钮获得焦点后，空格可能原生激活并重播；现在始终阻止该激活，长按只停止一次。
- 旧自检失败可能将内容显示在后来打开的遥控面板；所有结果按当前面板代次发布。
- 设置及校准保存失败仍可能显示成功；显式保存保持面板，校准区分「已生效」与「已保存」。
- 多条卡片在有限高度中可能被压缩并截断按钮；保持完整行高，在音效库内滚动。

浏览器以模拟 IPC 检查 920×660 和 660×500，底部停止始终可见，无横向溢出；
同时检查系统深色 / 浅色、Windows 平台指导、减少动态效果、详情调节、Tab / Escape 及真实按钮空格事件。
最终门禁、macOS 包与未执行的真机项目见[验证台账](验证台账.md)。
