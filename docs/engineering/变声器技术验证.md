# 变声器技术验证

> 范围：Signalsmith Stretch 与纯 Rust `pitch_shift` 的离线基准。
> 本文记录 macOS 本地与 Windows CI 的离线基准；Windows 真机与人工听感未完成，因此不给出最终选型。
> 设计依据见[变声器设计](变声器设计.md)，调研依据见[变声器调研](变声器调研.md)。

## 命令

30 秒离线矩阵：

```sh
cd tools/voice-spike
cargo run --release -- \
  --seconds 30 \
  --blocks 5,10,20,40 \
  --chunks 128,256,512 \
  --backend all \
  --json out/macos.json \
  --render out/macos
```

600 秒浸泡：

```sh
cd tools/voice-spike
cargo run --release -- \
  --seconds 600 \
  --blocks 10 \
  --chunks 128,512 \
  --backend signalsmith \
  --json out/macos-soak.json
```

Windows CI（GitHub Actions `windows-latest`，run 39708876551；同一 run 的 macOS 与 Windows job 均成功）：

```sh
cd tools/voice-spike
cargo run --release -- \
  --seconds 30 \
  --blocks 5,10,20,40 \
  --chunks 128,256,512 \
  --backend all \
  --json out/windows.json \
  --render out/windows
```

Windows 数据来自该 run 的 `voice-spike-windows` 工件；macOS 数据仍来自本地运行。

测量口径：

- 48 kHz 单声道，每用例 30 秒（浸泡 600 秒）合成谐波人声，基频 220 Hz；音高 +4 半音、共振峰 +3 半音。
- `--backend all` 同时包含 `passthrough` 基线。
- 库延迟为后端自报值；适配延迟 = 库延迟 + 一个算法块；实测延迟为脉冲响应峰值对齐（帧）。
- P50 / P99 / 最大为每次回调的处理耗时（毫秒）；P99 占比按回调周期计算，128 / 256 / 512 帧对应 2.667 / 5.333 / 10.667 ms。
- 分配计数包住处理循环；欠载按输入与输出积压超过一个算法块计数；溢出为适配器输出队列丢弃；NaN 恢复为 `pitch_shift` 恢复层触发次数。

## 音质

本轮只生成 +4 半音 / 共振峰 +3 的 A/B WAV，尚未人工试听。样本为 10 秒、48 kHz、单声道、16-bit：

- `tools/voice-spike/out/macos/wet-signalsmith.wav`

Windows CI 工件也包含同一 +4/+3 配置的 dry/wet WAV（`windows-artifact/windows/`），同样未人工试听。男声 −4 / −3、大幅 ±12、机器人 / 对讲机样本本轮均未生成。未做任何听感判断，不评估移调自然度、共振峰可辨度、颤音、金属声、爆音或音量变化。

## 结论

macOS 本地与 Windows CI 离线数据已取得；Windows 真机、真实设备与人工听感未完成，暂不选型。

Windows 数据来自 GitHub Actions `windows-latest` 的离线进程内基准，不是 Windows 真机声卡环回；证据等级为 B（离线进程内），Windows 真机 / 真实 WASAPI 仍为 D。

双端离线结果只覆盖进程内处理，按门槛逐项判定：

- 30 ms 预算：5 ms 块适配延迟 10.0 ms、10 ms 块 20.0 ms，双端均低于 30 ms；20 ms 块 40.0 ms、40 ms 块 80.0 ms，超出 30 ms，只作对比。
- P99 门槛：Signalsmith 全部用例 P99 / 回调周期 macOS 最大 5.94%，Windows CI 最大 8.24%（40 ms 块、128 帧回调：0.2196 ms / 2.667 ms），均低于 15%。
- 单次最坏耗时：30 秒矩阵 macOS 0.1992 ms、Windows 0.3879 ms；600 秒离线浸泡 macOS 512 帧最大 1.4342 ms；均低于 128 帧最小回调周期 2.667 ms。
- 分配 / 欠载 / 溢出 / NaN 恢复：macOS 30 秒矩阵与 600 秒离线浸泡、Windows CI 27 个用例全部为 0。
- 双端离线均满足 30 ms（5/10 ms 块）、P99 15%、最坏回调周期门槛；共振峰听感、Windows 真机、真实设备未验证；在 Windows 真机与人工听感完成前不选型、不进入生产实现计划。

`pitch_shift` 只做音高、无共振峰控制，仅作对照，不是完整档候选。
