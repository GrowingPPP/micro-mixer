# 变声器技术验证

> 范围：Signalsmith Stretch 与纯 Rust `pitch_shift` 的离线基准。
> 本文只记录 macOS 已执行部分；Windows 数据与人工听感未完成，因此不给出最终选型。
> 设计依据见[变声器设计](变声器设计.md)，调研依据见[变声器调研](变声器调研.md)。

## 环境

- 基准执行时提交：`34901c3c7363c990accc2578f1f9c8e3eac7da36`
- macOS：Apple M1 Pro（MacBookPro18,3）/ 32 GB / macOS 26.6.1（25G76）/ arm64
- Rust：rustc 1.99.0（b940084d7 2026-09-28）、cargo 1.99.0
- C/C++ 工具链：Apple clang 21.0.0（clang-2100.3.34.2）、Xcode 27.1
- 构建 profile：release，`opt-level = 3`、`lto = "thin"`、`codegen-units = 1`
- Signalsmith：Rust 包装 `signalsmith-stretch` 0.1.3，捆绑上游 `signalsmith-stretch.h` 1.3.1
- pitch_shift：2.1.0，外层带 NaN 恢复层；本文数据代表「pitch_shift + 恢复层」，不是纯上游行为
- Windows：未执行，当前环境没有 Windows 宿主

## 命令

30 秒离线矩阵：

```sh
cd tools/voice-spike
cargo run --release -- \
  --seconds 30 \
  --blocks 5,10,20,40 \
  --chunks 128,256,512 \
  --backend all \
  --json out/macos.json \
  --render out/macos
```

600 秒浸泡：

```sh
cd tools/voice-spike
cargo run --release -- \
  --seconds 600 \
  --blocks 10 \
  --chunks 128,512 \
  --backend signalsmith \
  --json out/macos-soak.json
```

测量口径：

- 48 kHz 单声道，每用例 30 秒（浸泡 600 秒）合成谐波人声，基频 220 Hz；音高 +4 半音、共振峰 +3 半音。
- `--backend all` 同时包含 `passthrough` 基线。
- 库延迟为后端自报值；适配延迟 = 库延迟 + 一个算法块；实测延迟为脉冲响应峰值对齐（帧）。
- P50 / P99 / 最大为每次回调的处理耗时（毫秒）；P99 占比按回调周期计算，128 / 256 / 512 帧对应 2.667 / 5.333 / 10.667 ms。
- 分配计数包住处理循环；欠载按输入与输出积压超过一个算法块计数；溢出为适配器输出队列丢弃；NaN 恢复为 `pitch_shift` 恢复层触发次数。

## 音质

A/B WAV 已生成，听感待人工。样本为 10 秒、48 kHz、单声道、16-bit：

- `tools/voice-spike/out/macos/dry.wav`
- `tools/voice-spike/out/macos/wet-signalsmith.wav`

本轮未做任何听感判断，不评估移调自然度、共振峰可辨度、颤音、金属声、爆音或音量变化。

## 结论

macOS 数据已取得；Windows 数据与人工听感未完成，暂不选型。

macOS 离线结果只覆盖进程内处理：10 ms 块长的 Signalsmith 实测延迟为 960 帧（20.0 ms），30 秒矩阵全部 Signalsmith 用例的 P99 / 回调周期不超过 5.94%，Rust 侧分配、欠载、适配器溢出与 NaN 恢复均为 0；600 秒浸泡无欠载。这些事实不等于端到端或听感门槛已经通过，也不构成后端或块长选型。
