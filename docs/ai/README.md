# AI 开发文档索引

本目录帮助 AI 开发助手定位当前实现、理解关键行为并选择验证范围。
这里不重复用户说明、完整编码规范或历史测试报告。

## 阅读入口

| 文档 | 作用 |
|---|---|
| [根 AGENTS.md](../../AGENTS.md) | 仓库级开发约定；目录中的 AGENTS.md 补充所属模块的约定 |
| [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) | 当前产品、模块边界、播放语义、配置与双端差异 |
| [WORKFLOW.md](WORKFLOW.md) | 开发流程、验证选择及交付方式 |
| [CONTRIBUTING.md](../../CONTRIBUTING.md) | 环境、编码规范、构建、检查及打包入口 |
| [README.md](../../README.md) | 面向用户的功能与使用说明 |

## 按问题定位

| 问题 | 补充资料 |
|---|---|
| 播放、试听、停止、切换、循环及异步竞争 | [播放操作组合回归](../engineering/播放操作组合回归.md) |
| 产品名称、双端产物路径及旧版本兼容性 | [打包名称与兼容性](../engineering/打包名称与兼容性.md) |
| 某项结论是否真实验证过 | [验证台账](../engineering/验证台账.md) |
| 设计与历史决策 | [文档索引](../README.md)；结合当前代码理解 |

## 信息边界

当前代码和回归描述实际行为；历史调研、M0 产物与计划文档记录当时的设计或证据。
交叉类型检查、受控音频样本、模拟 IPC 和真实设备验收证明的范围不同。
AI 文档不将测试数量、构建时间或尚未完成的计划固化为长期开发指令。
