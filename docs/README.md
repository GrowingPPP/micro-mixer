| 文档 | 内容 |

> **`验证台账.md` 值得单独说**：它回答的是"这句话到底有没有验过"。
> 本项目反复出现过同一类失误 —— **结论比证据强**（比如"关窗后引擎继续跑"
> 曾经只验了"进程还活着"就写成了结论）。台账把证据摊开，
> 明确标出哪些是端到端实测、哪些只是"命令返回成功"、哪些还没验。

## 约定

- 文档是**给未来的自己看的**：写清「当时为什么这么选」和「踩过什么坑」，
  比复述结论有用得多。
- 结论要**带上它成立的前提条件**。本项目有个典型例子：
  "权限声明可有可无"这条在 ad-hoc 签名下成立，换成强化运行时就不成立了 ——
  前两次的判断错就错在没写前提。
- 移动文档要**把所有交叉引用一起改掉并验证**，别留下死链接。
