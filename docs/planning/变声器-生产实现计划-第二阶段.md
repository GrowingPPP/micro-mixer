# 变声器完整首发实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有麦克风混音助手中交付完整、双端一致的变声首发功能：效果链、内置与用户预设、桌面与手机控制、三类热键、CLI、3 秒试听、打包与真机验收。

**Architecture:** 人声链继续位于采集侧漂移重采样之后、写环形缓冲之前；参数通过预分配快照在块边界发布，效果按「噪声门 → 移调 → 三段 EQ → 软削波 → 环形调制」处理。配置、Host、GUI、遥控与 CLI 共用同一套变声状态；试听在启用时从渲染侧人声限幅之后取音，在关闭或临时旁路时复用同一条人声链做只录不转发的预览。所有控制面变更串行提交，音频回调保持零分配、零加锁、零文件 IO。

**Tech Stack:** Rust 1.88、Tauri 2、`signalsmith-stretch` 0.1.3、现有 `audio-core` / `audio-session` / `app-config` / `hotkeys` / `remote`、手写 `apps/mixer-gui/dist`。

**本计划只描述方案、接口、测试与命令，不包含实现代码。**

## Global Constraints

- 实时 `process()` 路径不分配、不加锁、不做文件 IO、不调用平台设备 API。
- 音频流只在所有者线程创建和关闭；算法实例、试听记录区、限幅器在会话启动或测试构造时预分配。
- 人声链只处理真实麦克风；不进入音效、音效试听、监听、自检。
- 参数变化在块边界生效；同一块内使用同一份参数快照；预设切换是一次快照提交，不逐项生效。
- 效果开关与数值分离：EQ 开启且 0 dB 与 EQ 关闭是不同状态；所有效果关闭时直通。
- 变声启用时路径限幅默认 −3 dBFS，末端安全限幅默认 −1 dBFS；关闭或临时旁路时恢复现有单限幅链。
- 启用/关闭/旁路过渡的重复或跳过不超过算法延迟；无爆音、无欠载、无长断音；交叉淡化只遮蔽突变，不承诺零重复。
- 配置写入使用临时文件、刷新与原子重命名；单进程只有一个变声配置写入点；写入失败保留旧文件。
- 旧配置没有 `[voice]` 时视为关闭；未知键与未知预设字段保留往返；首次升级不改变现有音效行为。
- 内置预设由代码定义，不写入配置；内置预设只读；用户预设 ID 创建后不变。
- 选择预设不改变 `enabled`，也不自动启用变声；临时旁路只改变运行状态，不写配置。
- 临时旁路、未保存修改与可恢复草稿遵循设计文档的会话与退出语义。
- GUI 与手机页面进入 DOM 的用户文本按现有规则转义；面板沿用焦点约束、Escape、关闭与代次防护。
- 双端同步交付：macOS 与 Windows 使用同一份代码与锁文件；不能用一端编译成功替代另一端运行验收。
- GUI 与 CLI 默认开启 `voice` 特性；`audio-core` 的 C++ 后端只在 `voice` 特性下编译。
- `tools/win-cross-check.sh` 使用 `--no-default-features`，并显式打印「变声代码未参与本次交叉检查；Windows 原生 CI 与真机构建才是权威」。
- Windows 原生 CI 与真机构建使用默认特性，安装 LLVM/libclang 并编译完整 C++ 后端。
- 新增 Rust 测试名称使用中文行为描述；测试不使用真实声卡、系统默认设备或用户音频目录。
- 提交信息用中文，不加工具署名、工具名称或开发进度词。
- 不在本计划内修改托盘菜单；托盘继续只负责播放、停止与生命周期操作。

- `audio-core` 增加 `voice = ["dep:signalsmith-stretch"]`；保留 `voice-signalsmith = ["voice"]` 兼容旧命令，源码条件编译改用 `voice`。
- 效果器不依赖 C++ 后端，默认构建可测试。
- 更新所有 `VoiceParams` 结构体字面量，改用 `VoiceParams::neutral()` 加字段覆盖，避免新增字段造成编译失败；现有仅音高/共振峰测试保持原语义。

- [ ] **步骤 1: 写失败测试**
