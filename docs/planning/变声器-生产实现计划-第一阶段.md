# 变声器生产实现计划（第一阶段）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `audio-core` 中落地可旁路的 Signalsmith 人声链、tee 预热切换、人声/音效独立限幅和配置原子写入；不接入 GUI、Host、配置 UI 或用户可见开关。

**Architecture:** 人声链位于采集侧漂移重采样之后、写环形缓冲之前；启用时干声继续写环，湿声预热完成后由采集侧在块边界切换。渲染侧在变声启用时使用人声限幅、音效限幅和末端安全限幅；关闭时恢复现有单限幅链。代码通过 `audio-core` 的 `voice-signalsmith` 特性隔离，默认关闭，不改变现有构建与音频行为。

**Tech Stack:** Rust 1.88、`signalsmith-stretch` 0.1.3（C++/bindgen）、现有 `rtrb` 环形缓冲、`Limiter`、`DriftController`、`app-config` TOML。

## Global Constraints

- 实时 `process()` 路径不分配、不加锁、不做文件 IO、不调用平台设备 API。
- 音频流只在所有者线程创建和关闭；新增算法实例在会话启动或测试构造时创建，所有者线程回收。
- `voice-signalsmith` 默认关闭；关闭时现有 workspace、CLI、GUI、测试与 Windows 交叉检查行为不变。
- 人声链只处理真实麦克风；不进入音效、试听、监听、自检。
- 变声启用时路径限幅默认 −3 dBFS，末端安全限幅默认 −1 dBFS；关闭时恢复现有单限幅链。
- 启用/关闭的时间不连续必须量化：重复/跳过不超过算法延迟，无爆音、无欠载、无长断音。
- 新增 Rust 测试名称使用中文行为描述；测试不使用真实声卡、系统默认设备或用户音频目录。
- 提交信息用中文，不加工具署名或工具名称。
- 第一阶段不修改 `apps/`、`crates/remote`、`crates/hotkeys`、`crates/selftest`；不增加用户可见功能。

- 交叉淡化时长 20–30 ms；重复/跳过时长必须可测量，不承诺零空隙。
- 预热期不做额外漂移比率冻结；干声写环保证水位稳定。

### Task 5: 人声/音效独立限幅与停止尾部

**Files:**
- Modify: `crates/audio-core/src/engine.rs`

**Interfaces:**

  - `sfx_limiter: Option<Limiter>`
  - `safety_limiter: Limiter`
- 变声 Wet 时：麦克风增益 → 人声限幅（−3 dBFS）；音效增益 → 音效限幅（−3 dBFS）；相加 → 末端安全限幅（−1 dBFS）。
- Off/FadingOut 完成后：恢复现有「混音后单限幅」链。

2. `音效峰值不改变人声增益`：音效注入高峰值，人声输出与无音效峰值时一致。
3. `两路同时过载触发末端安全限幅`：两路同时接近上限，输出不超过 −1 dBFS，不削波。
4. `停止尾部包含音效限幅与末端限幅`：停止确认不早于两级限幅的尾部。
5. `关闭变声恢复单限幅`：Off 时输出与现有引擎基准逐样本一致。
