**关键路径上的三个瓶颈**（任何延误都会推后整体）：

1. **M1-6 透传打通** —— 第一个技术验证点，如果 Core Audio 集成有坑，会阻塞一切
2. **M1-8 ASRC 时钟漂移** —— 最容易低估的一块，技术难度高
3. **M2-12 稳定性防御** —— 决定产品口碑，不能压缩

## 10. 第一时间要启动的"长周期事项"

这些事耗时不在开发，而在采购/审核，**必须提前启动**：

| 事项 | 提前多久 | 说明 |
|---|---|---|
| Apple Developer Program 注册 | M3 前 | $99/年，审核可能数天 |
| **Windows EV 代码签名证书** | **M4 期间就启动** | 采购 + 验证可能要 2–4 周，别等到要用才买 |

| 商标 / 域名 | M1 期间 | 早定名字 |
