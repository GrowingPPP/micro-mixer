# 共用模块开发约定

适用于 `crates/`，在根 [AGENTS.md](../AGENTS.md) 基础上补充。
模块关系见 [项目上下文](../docs/ai/PROJECT_CONTEXT.md)。

## 音频核心与实时边界

- `audio-core` 保持平台无关，负责 DSP、解码、设备抽象和播放控制。文件解码及交叉淡化素材准备在回调外完成。
- `CaptureProcessor::process()` / `RenderProcessor::process()` 等实时 DSP 不分配、不加锁、不等待、不做 IO。
  不在其中释放大型 PCM、运行文件解码器、枚举设备、写日志或创建/关闭流。
- `audio-session` / GUI 试听的生命周期回调壳只尝试一次非阻塞 `try_lock`。
  输出获取失败保留预填零样本，输入获取失败跳过当前批；这不是 DSP 中允许阻塞锁的例外。
  保持关闭后脱离状态并在所有者线程回收 PCM 的机制。
- 增益、循环偏好、停止确认和健康指标通过已有原子量或预分配控制通道传递。
  主输出与监听提交保持接纳一致，任一路容量不足时不能让另一端抢先播放新音效。
- 全局 mic/sfx 增益与循环使用原子量；当前每槽位增益使用 `Command::SetGain`，试听增益使用独立原子控制。
  不能把所有控制都当作无队列参数，或删除控制侧生产者锁来追求实时 DSP 无锁。
- 切换期间先淡出旧音效再开始新音效；停止取消活动和待切换音效。保留样本级单音效断言及零分配回归。
- 循环在当前游标实时改变；关闭时当前一遍结束，不重置位置。保留从单次播放切到循环所需的预处理素材。
- 限幅器、重采样器的延迟和尾部样本也是停止行为的一部分；不能只清空播放标志就宣称不再出声。

## 会话与后端

- `audio-session::Session` 共用素材库、Playback 门控、监听与流所有者逻辑，GUI/CLI 不复制第二套生命周期实现。
- 播放屏障运行期间持有控制门锁；屏障中不得重入同一播放器命令接口。停止使用独立 epoch，不依赖可能排满的播放队列。
- 流在所有者线程打开和关闭；挂起、恢复、退出及失败清理均遵守所有权。
  后端可能保留回调闭包，关闭后必须脱离其状态；不能仅依赖闭包析构来释放 PCM。
- `StreamHealth` 按会话和用途独立：主会话、监听、试听、自检不能共享全局错误槽。
  看门狗按会话代次观察进度，旧回调不能重启或污染新会话。
- `backend-cpal` 的设备身份、格式与路由按实际方向解析；不要用列表下标充当稳定设备 ID。
- 保留输入、输出 FFI 回调的 panic 保护和失败静音。release 使用 unwind 不代表 panic 可以越过 FFI 边界。
- 使用可控 `AudioBackend` 验证生命周期、失败清理、错误隔离和实际 PCM；真实 CoreAudio/WASAPI 验收另行记录。

## 热键与远程入口

- `hotkeys` 保持注册、重绑、析构和事件分发的线程亲和性：macOS Carbon 在主线程，Windows 由专属消息循环所有者处理。
- 保留所有者线程的正常关闭与资源释放；不要恢复为泄漏管理器来回避析构问题。
- `remote` 的服务生命周期可关闭并释放监听端口；旧会话 handler 不得影响新会话。
  GUI 远程入口使用 routed handler；页面请求顺序、Host 票据与代次检查共同保证控制顺序。
- 网络回归使用 localhost、动态端口和受控素材，不依赖用户局域网 IP 或固定外部设备。

## 配置与目录

- `app-config` 保留结构化 `[[sounds]]` 与稳定 ID，旧格式迁移要有回归。
  标签与文件路径中的逗号、空格、引号及 Windows 反斜杠不能被当成分隔符丢失。
- 结构化配置中的标签值不能再次按标点拆分；界面标签输入的分隔规则与持久化数组是不同层次。
- GUI 文件夹载入替换库，添加文件追加；CLI 保留其文件与目录组合输入规则，共用扫描可合并多个目录。
  当前目录扫描不递归。格式扩展名过滤和实际解码支持要一致。
- 主目录与配置目录依赖平台规则；注入平台和环境函数测试 Windows 与 macOS，避免全局 `set_var` / `remove_var` 引起测试竞争。
- 配置写入保留完整快照及失败处理；当前 `Config::save` 直接写文件，未实现临时文件原子替换。
  取消选择或无效操作不能意外覆盖合法配置。

## 回归要求

优先执行改动 crate 的测试，再按 [工作流](../docs/ai/WORKFLOW.md) 执行共用门禁。
并发复现使用 channel、屏障或可控回调，不能只用延时等待碰运气。
验证正式播放、监听、试听互斥时断言实际样本；验证回收时检查所有者状态及素材引用，不能仅断言 stop 返回成功。
平台逻辑测试覆盖缺失/空环境变量、Unicode/空格路径、拒绝请求、容量不足和会话代次变化。
不要让共用回归依赖真实声卡、系统默认输入或用户音频目录；需要真机测试时使用另行准备的验收流程。
